# Website photos

- `hero/` contains page, homepage, and tour detail backgrounds. These use wide landscape photos (roughly 16:9) and are displayed with `object-cover`.
- `editorial/` contains supporting story photos used in page sections.
- `gallery/` contains the six unique gallery photos. The page lays them out in large and small tiles and opens each photo in the full-screen viewer.

Keep each image assigned to one visual location. Tour card covers remain in the parent `images/` folder; the four bundled tour detail pages have separate hero photos.
