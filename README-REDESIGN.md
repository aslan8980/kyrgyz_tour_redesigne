# Kyrgyz Tours — Cinematic Redesign

Updated visual direction based on the provided reference: full-screen mountain hero, left-aligned uppercase typography, white navigation over the image, dark gradient overlays, dark continuous public-page sections, Montserrat headings and Inter body text.

A locally generated Kyrgyzstan-inspired panorama is stored at `public/images/kyrgyzstan-hero.png`. Existing routes, Supabase client code and business logic were left in place.

## Run locally
1. Copy your own `.env.local` into the project root (never share or commit it).
2. Run `npm install`.
3. Run `npm run dev`.

The archive intentionally excludes `.env.local`, `node_modules`, build output, and `.git` metadata.
